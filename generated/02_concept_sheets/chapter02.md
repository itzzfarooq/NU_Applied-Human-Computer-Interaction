# Chapter 2: The Computer — Concept Sheet

---

## Displays & Visual Output

| Term | Definition |
|------|------------|
| **Pixel** | The smallest addressable element on a display screen. |
| **Resolution** | The number of pixels in each dimension of a display (e.g., 1920×1080); higher resolution means finer detail. |
| **Pixel density (PPI)** | Pixels per inch; higher PPI produces sharper images and text. |
| **Refresh rate** | How often the display image is redrawn per second (Hz); higher rates reduce flicker and motion blur. |
| **LCD (Liquid Crystal Display)** | A display technology using liquid crystals modulated by a backlight to produce images. |
| **OLED (Organic LED)** | A display technology where each pixel emits its own light; offers true blacks, high contrast, and thin form factors. |
| **Gamma** | The nonlinear relationship between pixel value and displayed luminance; affects perceived brightness and contrast. |
| **Contrast ratio** | The ratio of the luminance of the brightest white to the darkest black a display can produce. |
| **Colour gamut** | The range of colours a display can reproduce; wider gamut means more saturated colours. |
| **sRGB** | A standard colour space defining the range of colours for web and general-purpose displays. |
| **Bit depth** | The number of bits used to represent the colour of a single pixel; higher bit depth allows more colours. |
| **Anti-aliasing** | Techniques to smooth the jagged edges of rendered shapes and text by blending pixel colours at boundaries. |
| **Sub-pixel rendering** | Exploiting the individual red, green, and blue sub-pixels of an LCD to increase effective text resolution. |

## Input Devices

| Term | Definition |
|------|------------|
| **Mouse** | A pointing device detecting two-dimensional motion relative to a surface; the standard desktop input device. |
| **Trackball** | A pointing device where a ball is manipulated by the user's fingers while the device remains stationary. |
| **Touchpad** | A flat, touch-sensitive surface used as a pointing device, common on laptops. |
| **Stylus** | A pen-like input device used for direct manipulation on a display or digitizing tablet. |
| **Light pen** | A pointing device that detects light from a CRT display to determine screen position. |
| **Keyboard** | An input device consisting of a set of keys for entering text and commands. |
| **Touchscreen** | A display that also serves as an input device, detecting finger or stylus contact directly on the screen. |
| **Capacitive touchscreen** | A touchscreen detecting the electrical properties of the human body; supports multi-touch. |
| **Resistive touchscreen** | A touchscreen using pressure-sensitive layers; requires physical contact but cannot detect multi-touch. |
| **Motion sensor** | A device detecting movement, orientation, or acceleration (e.g., accelerometer, gyroscope). |
| **Gesture recognition** | The ability of a system to interpret human body movements (hand, body, facial) as input commands. |
| **Voice recognition** | Technology enabling a system to identify and process spoken language for input. |

## Colour Representation

| Term | Definition |
|------|------------|
| **Additive colour model (RGB)** | A colour model where red, green, and blue light are combined to produce colours; used in displays. |
| **Subtractive colour model (CMYK)** | A colour model where cyan, magenta, yellow, and black pigments are combined; used in printing. |
| **HSL/HSV** | Colour models representing colour as Hue, Saturation, and Lightness/Value; more intuitive for human use. |
| **Colour mapping** | Assigning data values to visual colour representations for effective data visualization. |
| **Colour blindness** | A condition where certain colour distinctions are impaired; most commonly red-green (affects ~8% of males). |
| **Colour-safe palettes** | Colour sets designed to be distinguishable by people with various forms of colour vision deficiency. |

## Audio Output

| Term | Definition |
|------|------------|
| **Audio output** | Sound produced by a computer through speakers, headphones, or built-in transducers. |
| **Speech synthesis** | The artificial production of human speech from text (Text-to-Speech, TTS). |
| **Earcons** | Abstract, non-verbal audio cues used to represent data, actions, or system events. |
| **Auditory display** | The use of sound to convey information or data to a user. |
| **Sonification** | The transformation of data into non-speech audio for the purpose of communication or analysis. |

---

## Haptic Output

| Term | Definition |
|------|------------|
| **Haptic** | Relating to the sense of touch; in HCI, referring to technologies that provide tactile feedback. |
| **Vibrotactile feedback** | Feedback delivered through vibration applied to the user's skin. |
| **Force feedback** | Haptic feedback that simulates physical resistance or forces encountered in virtual environments. |
| **Tactile display** | A device that presents information through touch, e.g., Braille displays. |
