# Chapter 1: The Human — Concept Sheet

---

## Perception & Sensation

| Term | Definition |
|------|------------|
| **Stimulus** | Any detectable change in the internal or external environment that activates a sensory receptor. |
| **Sensation** | The immediate response of sensory receptors (eyes, ears, skin) to a stimulus. |
| **Perception** | The process of organizing and interpreting sensory information to understand the environment. |
| **Absolute threshold** | The minimum intensity of a stimulus that can be detected at least 50% of the time. |
| **Just Noticeable Difference (JND)** | The smallest difference between two stimuli that can be detected 50% of the time. |
| **Weber's Law** | The JND is proportional to the magnitude of the stimulus (ΔI/I = k). |
| **Signal Detection Theory** | A theory distinguishing between the ability to detect a stimulus and the decision criterion used to judge its presence. |
| **Adaptation** | Decreased sensitivity to a prolonged or constant stimulus. |
| **Sensory register** | A brief, high-capacity buffer that holds incoming sensory information before it is processed or discarded. |

## Vision

| Term | Definition |
|------|------------|
| **Visual acuity** | The ability to resolve fine detail; measured by the smallest letter a person can read on a Snellen chart. |
| **Fovea** | The small central region of the retina with the highest density of cone cells; responsible for sharp central vision. |
| **Peripheral vision** | Vision outside the fovea; lower acuity but important for detecting motion and spatial context. |
| **Cone cells** | Photoreceptors concentrated in the fovea; responsible for colour vision and fine detail in bright light. |
| **Rod cells** | Photoreceptors distributed across the peripheral retina; responsible for low-light (scotopic) vision and motion detection. |
| **Accommodation** | The process by which the lens changes shape to focus on objects at varying distances. |
| **Dark adaptation** | The process by which the visual system increases sensitivity after transitioning from a bright to a dark environment. |
| **Bright adaptation** | The rapid recovery of visual sensitivity when moving from dark to bright conditions. |
| **Colour constancy** | The perception of an object's colour as relatively stable despite changes in illumination. |
| **Trichromatic theory** | The theory that three types of cones (red, green, blue) are the basis of colour perception. |
| **Opponent-process theory** | The theory that colour is processed in opposing pairs (red–green, blue–yellow, black–white). |
| **Visual field** | The total area visible to the eye when the gaze is fixed in one direction. |
| **Change blindness** | The failure to detect changes in a visual scene when they occur during a brief interruption or saccade. |
| **Inattentional blindness** | The failure to notice a fully visible but unexpected object because attention is engaged elsewhere. |
| **Preattentive processing** | The automatic, rapid processing of certain visual features (colour, orientation, motion) before focused attention. |
| **Pop-out effect** | When a target item with a unique feature appears to "pop out" from a display, detected in parallel regardless of set size. |
| **Fitts's Law** | Movement time to a target is a function of the distance to and width of the target: MT = a + b·log₂(2D/W). |

## Hearing (Audition)

| Term | Definition |
|------|------------|
| **Frequency** | The number of cycles per second of a sound wave, measured in Hertz (Hz); perceived as pitch. |
| **Amplitude** | The magnitude of a sound wave's pressure variation; perceived as loudness. |
| **Decibel (dB)** | A logarithmic unit used to express the ratio of two sound pressure levels. |
| **Auditory threshold** | The minimum sound intensity detectable at a given frequency. |
| **Cocktail party effect** | The ability to focus on one auditory source while filtering out others in a noisy environment. |
| **Earcons** | Abstract, auditory icons used to convey information in a non-speech audio format. |
| **Auditory icons** | Everyday sounds mapped to computer events to convey meaning through analogy. |
| **Masking** | The phenomenon where one sound makes another sound inaudible or harder to detect. |
| **Pitch resolution** | The ability to discriminate between two sounds of slightly different frequency. |

## Touch (Haptics & Somatosensation)

| Term | Definition |
|------|------------|
| **Mechanoreceptors** | Sensory receptors in the skin that respond to pressure, vibration, and stretch. |
| **Two-point threshold** | The minimum distance at which two simultaneous touch stimuli are perceived as separate. |
| **Haptic feedback** | Tactile information returned to the user through vibration, force, or motion. |
| **Proprioception** | The sense of the relative position of body parts and the effort used in movement. |

## Movement & Motor Control

| Term | Definition |
|------|------------|
| **Steering law (Accot & Zhai)** | Predicts movement time for navigating through a path or tunnel: MT = a + b·(Length/Width). |
| **Hick's Law** | Decision time increases logarithmically with the number of choices: RT = a + b·log₂(n). |
| **GOMS** | A model predicting user performance based on Goals, Operators, Methods, and Selection rules. |
| **KLM (Keystroke-Level Model)** | A GOMS variant that decomposes tasks into primitive operators (keystrokes, pointing, mental, homing, system response). |
| **Motor noise** | Random variability in motor output that limits the precision of movements. |
| **Feedback delay** | The time between a user's action and the system's response; affects perceived system responsiveness. |

## Memory & Cognition

| Term | Definition |
|------|------------|
| **Sensory memory** | Brief, modality-specific storage (iconic for vision, echoic for audition) lasting hundreds of milliseconds to a few seconds. |
| **Short-term memory (STM)** | Limited-capacity store (~7±2 items) that holds information currently in use; duration ~15–30 seconds without rehearsal. |
| **Working memory** | A multi-component system (Baddeley) comprising the phonological loop, visuospatial sketchpad, central executive, and episodic buffer. |
| **Long-term memory (LTM)** | Virtually unlimited-capacity store for information retained over long periods; includes declarative (explicit) and procedural (implicit) memory. |
| **Chunking** | Grouping individual items into larger meaningful units to increase effective STM capacity. |
| **Encoding** | The process of converting sensory input into a mental representation for storage. |
| **Retrieval** | The process of accessing stored information from long-term memory. |
| **Forgetting curve** | Ebbinghaus's exponential decay curve showing how memory retention decreases over time without reinforcement. |
| **Spacing effect** | The finding that distributed study (spaced practice) leads to better long-term retention than massed study (cramming). |
| **Primacy effect** | Better recall of items presented at the beginning of a list. |
| **Recency effect** | Better recall of items presented at the end of a list. |
| **Recognition vs. recall** | Recognition (identifying previously encountered items) is generally easier and less error-prone than recall (generating items from memory). |
| **Mental model** | An internal, simplified representation of how a system works, used to reason about and predict system behaviour. |
| **Schema** | A knowledge structure in long-term memory that organizes information about a concept or situation. |
| **Script** | A type of schema describing a sequence of events in a familiar situation (e.g., ordering food at a restaurant). |
| **Distributed cognition** | A theory emphasizing that cognitive processes are distributed across individuals, artefacts, and the environment. |
| **External cognition** | Cognitive processes that are offloaded to external artefacts (notes, diagrams, calculators). |

## Thinking & Problem Solving

| Term | Definition |
|------|------------|
| **Heuristic** | A mental shortcut or rule of thumb that simplifies decision-making and problem-solving. |
| **Confirmation bias** | The tendency to seek, interpret, and remember information that confirms one's pre-existing beliefs. |
| **Anchoring** | The tendency to rely too heavily on the first piece of information encountered when making decisions. |
| **Functional fixedness** | The inability to see an object as useful for a purpose other than its typical function. |
| **Gulf of execution** | The gap between a user's intention and the actions required to carry it out on a system. |
| **Gulf of evaluation** | The gap between the system's output and the user's ability to interpret that output and determine the system state. |
| **Error** | An incorrect action resulting from a gap between the user's goal and their understanding of the system. |
| **Slip** | An error in which the wrong action is performed (correct goal, wrong execution). |
| **Mistake** | An error in which the wrong goal is formed (incorrect plan, correct execution of that plan). |

## Emotion & Affect

| Term | Definition |
|------|------------|
| **Affect** | A broad term for feelings and moods, encompassing both emotional states and trait dispositions. |
| **Usability** | The extent to which a product can be used effectively, efficiently, and satisfactorily by specified users for specified goals. |
| **User experience (UX)** | The totality of a person's perceptions, emotions, and responses resulting from the use of a product or service. |
| **Flow** | A state of deep absorption and optimal experience occurring when skill level matches challenge difficulty. |
| **Emotional design** | Designing products to elicit positive emotional responses, improving engagement and satisfaction. |
